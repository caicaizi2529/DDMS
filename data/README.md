# Data

Compressed preprocessed data used by the scripts:

| Set | Archive |
| --- | --- |
| Ciao | `ciao/dataset.zip` |
| Epinions | `epinions/dataset.pkl.zip` |
| Yelp | `yelp/dataset.pkl.zip` |

Extract each archive in its own folder so that `dataset.pkl` is beside the
archive. The extracted files are excluded by `.gitignore`.
